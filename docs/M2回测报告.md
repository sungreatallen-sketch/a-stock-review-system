# M2 回测报告（2026-08-11）

## 策略定义
- 标的池：近 5 日主力净流入前 8 的申万行业 → 板块内强势个股 + 全市场成交额前 25 + 涨停股（剔除 ST/北交所/异常数据）
- 打分：板块强度 + 个股强度（涨幅）+ 资金活跃（成交额）+ 换手率 + 情绪 + 质量扣分
- **量比过滤**：剔除量比 > 2.0 的"放巨量"标的（回测发现放量股次日开盘被砸）
- 交易规则：T 日收盘价买入，T+1 日开盘价卖出（与实盘一致）

## 关键发现（基于 40-60 日因子归因）
1. **量比是最强因子**：低量比分位次日 +0.41%；高量比（放巨量）次日 **-2.07%、胜率 9.3%** → 已内置为过滤规则
2. 大成交额（>=5亿）热门股次日低开概率高；1-5 亿成交额的强势股相对占优
3. 市场环境（指数 5 日动量）过滤在本样本无效（弱市获利回吐），未启用
4. 简单"追高"规则（无量比过滤）显著跑输指数，已废弃

## 结论与边界
- 当前规则版策略在样本内**跑赢指数同口径约 0.2%/笔**，绝对收益仍受弱市拖累
- 样本窗口较短、未含牛市/震荡市验证；实盘前需持续滚动回测
- 下一步（M3）：消息面/公告/龙虎榜纳入 + DeepSeek 研判 + 模拟盘跟踪验证
