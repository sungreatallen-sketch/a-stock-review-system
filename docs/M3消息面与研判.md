# M3 消息面 + LLM 研判（已完成）

## 新增能力
1. **消息面扫描**（同舟 doc_search）：候选股近 5 日新闻 / 公告 / 事件
   - 含来源（东方财富等）与原文链接，关键词情绪初筛（利好/利空/中性）
   - 检索不到如实标注"无检索到消息"
2. **DeepSeek 综合研判**（deepseek-v4-flash）：
   - 输入：规则候选池（评分/逻辑）+ 消息面 + 当日市场环境（指数/涨停/连板）
   - 输出：市场判断 + Top3（买入逻辑 / 风险点 / 情绪分 / 置信度）
   - 铁律：只能引用喂入的真实数据，禁止编造；无数据标"不确定"
   - 输出经"候选池白名单"校验，防止模型幻觉出池外标的

## 示例（2026-08-11）
- 市场判断：上证收跌 0.82%、创业板逆势 +0.34%、涨停 58 家、最高 6 连板，结构性活跃
- Top3：联芸科技（电子/高置信，4 条利好）、云路股份（有色，稀土回暖）、北化股份（基础化工涨停，净利翻倍，提示 2 条利空）
- 风险提示：模型基于量比/换手/消息面给出（如云路股份换手 1.69% 流动性一般）

## 模拟盘跟踪
- `run_cli.py track record`：记录当日预测 → SQLite
- `run_cli.py track settle --date 次日`：回填次日开盘价，计算收益
- `run_cli.py track stats`：命中率/平均收益/最优最差/近期明细
- 建议：先跑 2-4 周模拟盘再考虑实盘

## 使用
```bash
.venv/bin/python run_cli.py predict              # 完整预测（规则+消息面+LLM）
.venv/bin/python run_cli.py review               # 复盘+预测一体报告
.venv/bin/python run_cli.py track record|settle|stats
飞书：发「预测」或「复盘」
```
