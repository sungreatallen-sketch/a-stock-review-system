# M4 模拟盘自动化（已完成）

## 自动结算
- 每次运行「复盘/预测」（CLI 或飞书）时，自动结算**上一期**预测：用次日真实开盘价回填，计算收益
- 飞书发「结算」/「命中率」→ 立即结算并返回统计卡片
- launchd 定时任务 `com.ashare.settle`：**工作日 15:30** 自动执行 `track auto`（兜底，即使当天没手动触发）

## 验证（真实数据）
用 2026-08-10 预测 + 2026-08-11 真实开盘价验证全链路：
- 联芸科技 买57.85 → 卖57.28（-0.99%）
- 长城科技 买26.49 → 卖26.38（-0.42%）
- 云路股份 买75.60 → 卖74.88（-0.95%）
结算、统计、清理均正常。

## 使用
```bash
.venv/bin/python run_cli.py track record     # 记录当日预测（复盘/预测时自动记录）
.venv/bin/python run_cli.py track auto       # 自动结算最近一期
.venv/bin/python run_cli.py track stats      # 命中率统计
飞书：发「复盘」「预测」「结算」「命中率」
```

## 建议的每日流程
1. 收盘后（15:00）飞书发「复盘」或「预测」→ 自动记录本期预测
2. 次日 15:30 定时任务自动结算（或随时发「结算」）
3. 每周看 `track stats` 评估命中率，再决定是否调参
