## 3. 回滚操作手册
### 3.1 代码回滚
```bash
cd /Users/yage/Documents/我的预测系统
git log --oneline | head -30        # 查提交
git revert <hash>                   # 撤销某次变更（生成新的反向提交）
# 或仅还原某文件
git checkout <hash> -- app/predict/scoring.py
```
### 3.2 服务重启（改代码/模板后必须）
```bash
launchctl kickstart -k gui/$(id -u)/com.ashare.bot      # 机器人
launchctl kickstart -k gui/$(id -u)/com.ashare.server   # 报告服务（HTML模板变更必重启）
```
### 3.3 数据回滚（SQLite）
```bash
# 撤销某日错误结算
.venv/bin/python -c "
import sqlite3
from app.config import paths
c = sqlite3.connect(paths()['data'] / 'a_share.db')
c.execute('DELETE FROM prediction_results WHERE date=?', ('2026-08-12',))
c.commit()"
# 重新结算：.venv/bin/python run_cli.py track auto
```
