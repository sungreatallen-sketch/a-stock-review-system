## 3. 总体架构
```
飞书(手动触发) → 编排层 workflow.run_review
  → 数据采集：ego浏览器(东财 push2delay 优先) + MCP(通达信/同舟/Wind 兜底链)
  → 交叉验证(validator 双源容差)
  → 存储(SQLite + reports/*.json)
  → 预测六步：S1板块(10日) → S2候选池 → S3打分 → S4消息面(含龙虎榜) → S5 LLM研判(3只+买卖计划) → S6回测命中率
  → HTML报告(手机自适应) → 本地Web服务 :8787
  → 规则预读(R30) + 合规自检(R20)
```

## 4. 关键机制（改了容易踩坑，务必先看）
| 机制 | 要点 | 引用 |
|---|---|---|
| 数据源 | ego优先；MCP自动发现端口/token（WorkBuddy重启端口会变）；MCP连不上必须上报用户(R03) | R01-R03/R27 |
| 网页抓取 | 东财 push2delay 备用域名（主域名会限流） | R01/I06 |
| 评估口径 | **昨收买→今收卖（收盘-收盘）**，命中率按此计算 | R10/R14/I25 |
| 同日复用 | 同日预测锁定复用；报告完整(板块+预测+跟踪)才复用，否则强制重生成 | R11/R16 |
| 去重 | 消息级+回复级（键=消息ID+类型） | R17 |
| 手机访问 | 卡片给 IP 主链接+.local 备用+当前IP；**IP 取默认路由物理网卡，排除 utun/tun** | R09/I26 |
| 代理 | 飞书/DeepSeek 直连（NO_PROXY+trust_env=False），不走 clash 系统代理 | I02 |
| 变更日志 | 任何修复/更新必须记 CHG+ISSUE（R29），无日志=未完成 | R29 |
| 运行预读 | 运行前必须预读 execution_rules.yaml，失败禁止运行（R30） | R30 |
| 因子 | 投资经验因子隔离于 factors/，未验证未批准不得接入（R28） | R28 |
