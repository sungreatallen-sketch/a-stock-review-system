## 核心能力
1. 飞书发「复盘」→ 完整报告卡片 + HTML（市场/情绪/板块/资金/龙虎榜/昨日复盘/今日预测/合规自检）
2. 评估口径：昨日标的按 **昨收买→今收卖** 计算命中率（当前 08-11 期 66.7%，平均 +2.86%）
3. 数据真实可溯源：ego 优先、MCP 兜底、双源验证、连不上上报
4. 规则驱动：30 条执行规则，运行前预读，输出附合规自检
