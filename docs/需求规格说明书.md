# A股收盘复盘与次日标的预测系统 · 需求规格说明书

> 文档编号：REQ-001 ｜ 版本：v1.0（原始需求固定版）
> 状态：**已固定（本文件是原始需求的权威基线，后续变更需走工程变更流程）**
> 定稿日期：2026-08-12（经完整上下文巡视，从对话中提取并固化）

## 1. 系统目标
开发一个 **A股收盘复盘 + 次日标的预测** agent：
- 收盘后自动/手动生成当日复盘
- 基于复盘与历史经验生成次日关注标的
- 结果通过飞书下发、浏览器 HTML 可视化（手机可打开）

## 2. 运行环境（固定）
- Mac Air M5 / 16G / 1T
- 模型：DeepSeek V4 Flash（API 可配置）
- 数据源：WorkBuddy 内三个 MCP（通达信 / 同舟金融研究 / Wind）
- 浏览器抓取：ego-browser（优先）

## 3. 功能需求

### FR1 入口（飞书）
- 飞书机器人作为命令入口，**手动触发**
- 命令：复盘 / 预测 / 结算 / 命中率 / 规则
- 结果通过飞书卡片返回，含可打开的 HTML 报告链接

### FR2 收盘复盘（数据项，全部必取）
| 类别 | 数据项 | 字段 |
|---|---|---|
| 市场指数 | 上证/深证成指/创业板指/科创50 | 收盘价、涨跌幅、成交额 |
| 市场情绪 | 涨停数、跌停数、最高连板、炸板数 | 数量/高度 |
| 板块数据 | 涨幅前10板块（行业+概念） | 板块涨跌幅、龙头股 |
| 资金数据 | 主力资金流向、北向资金、龙虎榜 | 金额/明细 |
- 每个数据项**必须注明来源**（网页/MCP）
- 无法获取的明确标注 **"数据不可获取"**，**禁止编造**

### FR3 标的预测
- 交易规则：**T+1 超短**——T 日收盘前买入、T+1 日开盘后卖出
- 每日输出 **3 只**
- 选股范围：**不扫全市场**，聚焦近 **7-10 日强势板块**及板块内强势个股、资金活跃标的，**剔除 ST**
- 必须纳入**消息面**（公告/新闻/龙虎榜）
- 预测流程为**六步核心算法**（见架构文档 S1–S6）

### FR4 输出与展示
- 结构化 JSON（date / market_index / emotion / sector_rank / capital_flow / source）
- **一个 HTML 汇总**：复盘 + 预测 + 跟踪，手机（iPhone）可打开，同 Wi-Fi 访问

### FR5 跟踪与评估（核心）
- **昨日给出的标的，次日必须评估**（真实次日数据回填）
- **必须给出命中率评分**：当日命中、累计命中率、平均收益
- 评估口径：**开盘收益 + 收盘收益双口径**

### FR6 回测
- 实盘前必须回测验证策略
- 历史 N 日命中率随流程输出

## 4. 数据源规则（固定）
1. **优先 ego 浏览器**抓公开网页（省钱）
2. 拿不到/不全 → **依次调用 MCP**（按数据类型：通达信→同舟→Wind）
3. MCP 连不上 → **必须上报用户审查**，禁止静默降级
4. 关键数据**双源交叉验证**，容差内一致才输出
5. 每条数据**可溯源**

## 5. 非功能需求
- **数据真实性**：一切输出以真实数据为准，禁止编造
- **手机可访问**：同 Wi-Fi 下 iPhone 能打开报告
- **持久运行**：插电合盖不中断（防休眠）
- **防重复**：同一消息只处理一次，防 token 浪费
- **规则可执行**：执行规则作为核心算法强制约束，每次输出附合规自检

## 6. 验收标准（原始基线）
1. 飞书发「复盘」→ 返回真实、可溯源、含全部数据项的 JSON + 可打开的 HTML
2. 飞书发「预测」→ 返回 3 只标的（含逻辑、风险、买卖计划）
3. 复盘必须包含**昨日标的评估 + 命中率**
4. 全部数据项可溯源；拿不到的标"数据不可获取"
5. 同 Wi-Fi 手机可打开 HTML；无 JS 错误
