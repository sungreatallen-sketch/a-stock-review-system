# 工程因子库（investment_factors）

> 版本：v1.0 ｜ 来源：用户投资经验假设库（investment_hypotheses.yaml）
> **隔离保证：预测系统当前不读取本文件**，因子仅作管理与未来接入候选。

## 用途
把你投资经验形成的假设因子**工程化、可追踪、可验证**，但**不放进系统**：
- 避免未经验证的因子污染现有策略
- 每个因子独立回测 → 验证 → 用户批准 → 才可接入系统

## 因子生命周期（接入规则）
```
假设(H) → 因子(F) → 独立回测 → validated / invalidated → 用户批准 → 接入系统(R28)
```
| 阶段 | 状态 | 说明 |
|---|---|---|
| 候选 | hypothesis | 未验证，仅登记定义与候选信号 |
| 已验证 | validated | 独立回测显著（如 H013 死水股规避） |
| 证伪 | invalidated | 回测未发现显著效应（如 H003 洗盘拉升） |
| 可接入 | approved | validated + 用户批准，才允许进入 app/predict |

## 文件结构
- `investment_factors.yaml`：46 个因子（F001–F046），含来源假设、定义、数据需求、测试周期、验证记录、接入状态
- 每个因子标注 `system_integration: 未接入（等待成熟）`

## 现有验证结论（批量回测，见 docs/假设库批量回测.md）
- 相对有证据：F 相关 H013（死水股规避）、H009（回光返照卖出）、H007（压力位次日）
- 无显著：H002（放量）、H003（洗盘）、H006（支撑位买入）
- 方向相反：H001（高活跃反而跑输）
> 注意：以上为初步回测（样本受限），全部维持 hypothesis，未经用户批准不得接入。
